# NFTMintV2

A test ERC-721 NFT contract deployed on the Sepolia testnet.

## Features
- Max supply of 120 NFTs
- Mint deadline: 30 Dec 2026, 23:59:59 (Kenya time)
- Owner can pause and resume minting
- Public mint function that anyone can call

## Tech
- Solidity 0.8.34
- OpenZeppelin ERC721 and Ownable
- Built and deployed with Remix and MetaMask

## Live contract
Verified on Sepolia Etherscan:

[CONTRACT_LINK_HERE](https://sepolia.etherscan.io/address/0xC2150d3715076BB061a8B71f0f9b200b65DF30A2#writeContract)

## How to mint
1. Install MetaMask and switch to the Sepolia network
2. Get Sepolia test ETH from a faucet
3. Open the contract link, then go to Contract, Write Contract
4. Click Connect to Web3, open mint and click Write
